# 0002: 構造で覆えない問いはスキーマの不備として塞ぐ

- 状態: 承認済み
- 日付: 2026-09-20
- 覆す: なし

## 決定

構造層だけで答えられない問いは「答えられない問い」ではなく「直すべき不備」として扱う。不備は「選択肢が足りない」(語彙進化で自動追加)と「項目がない」(追加のみの新版)の 2 種類で、埋め直しは該当範囲の差分で行う。到達目標は目録の問いのすべてであり、N 件中 M 件ではない。

## 理由

逐語層への定義適用を正規の経路として認めると構造層を完全にする動機が消え、LLM を扱える人しか問いを立てられない状態に戻る。
