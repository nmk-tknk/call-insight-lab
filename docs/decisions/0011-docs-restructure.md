## 理由

v0.2〜v0.3 時代の文書が v0.4 の文書と並び、原則が 06・13・12 に分散し、相互参照が網の目になっている。目的別に 1 文書ずつにすれば、読む順が決まり、原則の置き場が 1 つになり、以後の適用ターンで整合を取る範囲が小さくなる。
