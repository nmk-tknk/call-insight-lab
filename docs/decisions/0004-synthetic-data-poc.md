# 0004: PoC は合成データで行う

- 状態: 承認済み

## 決定

実データと既知事例は現時点で使えないため、PoC は合成通話で行う。急増の真因は生成器が乱択して封印ファイルに書き、分析者は結果を出してから開ける。合成データで測れない基準(外部整合、分析者の体感)は v1 まで保留する。
