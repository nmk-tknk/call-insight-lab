# 0001: 半構造化の 3 層と、項目固定・選択肢育成の原則

- 状態: 承認済み
- 日付: 2026-09-20
- 覆す: なし(06 の旧原則 1・2 の言い換え)

## 決定

通話は「原文(逐語)/ 構造(用件ごとに固定の項目へ閉じた語彙の値)/ 根拠(値と原文の対応)」の 3 層で保存する。構造の項目は「通話で言われうることの役割」で固定し、問いから逆算しない。各項目の選択肢は語彙進化ループで育てる。集計は構造層に対する SQL だけで完結させる。

## 理由

キーワード検索は文脈を失い、全文脈保持は集計のたびに全負担を押し付ける。折衷が半構造化であり、項目を役割で固定すれば新しい問いは新しいタグではなく既存項目の値の組合せになる。
