# 0005: 業種は自動車保険(事故対応外)。書き起こしの様式、業務メタデータなし、マスキング未実施

- 状態: 承認済み
- 日付: 2026-09-20
- 覆す: なし

## 決定

業種は自動車保険で、事故対応(事故受付・保険金請求・示談)はスコープ外。書き起こしは話者分離・ターン分割済み、フィラー残存、句読点なし、数字表記混在、漢字誤りあり。業務メタデータ(IVR、キュー、後処理コード、CRM ケース ID)はない。個人情報はマスキング未実施で、取込時にローカルでマスキングする。マスキング済みなら外部 API に送ってよい。
