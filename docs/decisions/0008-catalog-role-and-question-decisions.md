# 0008: 目録の役割はテーマの表現可能性の試験。問い 31〜34 不採用、23 は時間、45 追加

- 状態: 承認済み
- 日付: 2026-09-21
- 覆す: 目録を「部署ごとの問いを採否する表」とした位置づけ

## 決定

分析ニーズの目録は「特定のテーマを拾えるか」を「表現できるか / 値があるか / 信頼できるか」に分解し、前 2 者を確かめる試験集である。テーマは構造層の項目の条件式で、条件は 7 族(何についてか / どう至ったか / どう進んだか / 何を言葉にしたか / 通話の形 / いつ・何と比べるか / 誰が・誰に)から選ぶ。問いの個別の採否ではなく、7 族で書けないテーマの有無を依頼者に確認する。問い 31〜34(コンプライアンス系)は不採用、23 はターン数ではなく時間で測る、45(未解決の理由の内訳)を追加する。
