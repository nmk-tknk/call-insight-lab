# 0012: A1 の 14 例の判定と、それで見つかった不備の塞ぎ方

- 状態: 草案
- 日付: 2026-09-22
- 覆す: なし
- 覆された: (後から追記のみ)

## 決定

1. 依頼者が 2026-09-22 に挙げた 14 例は、1 例(契約者本人以外の代理連絡の件数)を除き 7 族で書ける。7 族の枠組みは変えない。
2. 「誰が・誰に」の族に、取込データだけでなく明言の置き場を足す。顧客の発話行為「立場を述べる」(`state_caller_role`。値: 本人 / 家族 / 代理人 / 代理店 / 法人担当 / その他)を追加し、通話単位で持つ(用件には帰属させない)。
3. 値と対象を次のとおり追加する(語彙の追加であり、スキーマの不備ではない)。
   - 対象: 代理店(`object_kind = party`。当社窓口・代理店・販売店)と、その子「代理店の連絡先」。書面の部位(証券の割引欄など)は目録 #12 のとおり書面の子として置く。
   - 主張コード: 「同条件更新なら保険料は変わらない」を既知の誤解一覧の候補に足す(正誤は A6 と併せて依頼者が確認)。
   - きっかけ `life_event` の子値: 引越し / 結婚 / 離婚 / 相続 / 譲渡 / 免許更新 / 家族の免許取得 / 車の購入 / 車の処分。
   - 動機 `service_dissatisfaction` の子値: 連絡がない / 説明が違った / 手続きが遅い / 態度 / つながらない。
   - S16 の案内先に「別の窓口へ掛け直し」、断った理由に「窓口違い」を足す。
4. 導出規則の修正: 間接的な誤解の判定で、「主張」だけでなく「不具合を報告する」にオペレータの「訂正」が続く場合も間接(誤解)とする。
5. 2〜4 は v0.4.1(S14〜S16)に含めて 1 回で適用する。

## 理由

14 例のうち 13 例は既存の族に置き場があり、足りないのは値と対象の粒度だけである(原則 1: 項目固定・選択肢育成)。代理連絡の件数だけは、7 族の「誰が・誰に」に明言の置き場がなく、原則 5 により不備として塞ぐ。「届かない」の主張が不具合報告として抽出される揺れは規則で吸収でき、再抽出を要しない。
