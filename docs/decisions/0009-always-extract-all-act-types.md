# 0009: 発話行為は問いの有無によらず全種類を抽出する

- 状態: 草案
- 日付: 2026-09-21
- 覆す: 「不採用の問いに対応する発話行為は抽出指示から外す」とした 2026-09-21 の説明

## 決定

発話行為の種類は業種によらない役割の一覧であり、目録の問いの採否にかかわらず常に全種類を抽出する。問いの不採用は「集計・レシピを作らない」ことだけを意味する。「語彙」のうち業種に依存するのは対象と主張の値の層だけで、発話行為の種類・側面・動機・導出規則は業種を変えても持ち越す。

## 理由

抽出範囲を問いの有無で増減させると構造化が問いに依存し、原則 1 に反する。
