# 0007: v0.4 — 注釈は構造と明言のみ、判断は導出。感情は表出のみ

- 状態: 承認済み
- 日付: 2026-09-20
- 覆す: v0.3.1 の判断列(混乱の型・動機・結果・受容・横断フラグ・感情)を LLM が抽出時に埋める方式

## 決定

LLM が注釈層に書くのは構造(局面、用件の切り出し、ターン帰属)と発話行為(誰が何を明言したか。引用付き)だけとする。混乱の型・動機・結果・受容・横断フラグ・感情は保存せず、発話行為と業務知識表(既知の誤解一覧)から SQL のビューで導く。明言されていない含意は「不明」として数える。感情は表出のみを事実とし、口調からの推定はしない。内面の推定が要る場合は「推定」と名の付く別の実行に隔離する。v0.3.1 までのスキーマは依頼者が内容を理解していない前提で扱い、v0.4 を正とする。

## 理由

事実と推論を分離し、判断の定義変更を SQL の修正で済ませて再抽出をなくすため。判断の根拠を人に読める規則にするため。
