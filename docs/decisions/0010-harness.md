# 0010: ハーネス導入 — 決定記録、発言種別、議論と適用の分離

- 状態: 承認済み
- 日付: 2026-09-21
- 覆す: なし

## 決定

1. 設計・方針の決定は `docs/decisions/` の決定記録に 1 決定 1 ファイルで記録する。承認済みの記録は書き換えず、覆すときは新しい記録で `覆す` を書く。09 の台帳は決定の索引と未決の論点の一覧に縮め、決定の本文は記録に置く。
2. 設計に関する発言には「決定 / 提案 / 仮説 / 訂正」の種別を付ける。文書に書けるのは決定だけ。訂正のときは何をどの発言から覆すかを書く。
3. 依頼者が明示的に「適用」と言わない限り文書を編集しない。議論の結果は決定記録の草案として提示し、承認後に一括で適用する。docs 配下の編集は hook で機械的に検査する: `docs/decisions/APPLY` に記録番号と当日の日付が書かれ、その記録が承認済みで、編集対象がその記録の「影響を受ける文書」に含まれる場合だけ通す。

## 理由

提案を決定として書き、議論の途中で文書を書き換え、文書間の不整合を放置した反省による。
