# 決定記録(ADR)

このディレクトリは、本リポジトリの設計・方針に関する **決定** の唯一の記録である。会話で合意した内容は、ここに 1 決定 1 ファイルで記録される。

## 規則

1. **1 決定 1 ファイル。** `NNNN-<短い題>.md`。番号は連番で欠番を作らない。
2. **承認済みの記録は書き換えない。** 覆すときは新しい記録を作り、`覆す: NNNN` を書く。覆された側には後から `覆された: MMMM` の 1 行だけを追記してよい(それ以外の変更は禁止)。
3. **状態は 2 つ。** `草案`(提案中。編集自由)と `承認済み`(依頼者が承認した。以後は不変)。
4. **docs 配下の文書の編集は、承認済みの記録に「影響を受ける文書」として列挙された文書に限る。** 編集の前に `docs/decisions/APPLY` に記録番号と日付を書き、編集が終わったら削除する(hook が検査する。CLAUDE.md 参照)。
5. **記録に書くのは決定だけ。** 議論の経過や候補案は書かない(会話に残る)。理由は決定を理解するのに必要な最小限にする。

## テンプレート

`0000-template.md` を複製する。必須の見出しは 決定 / 覆す / 理由 / 影響を受ける文書 / 承認 の 5 つ。
